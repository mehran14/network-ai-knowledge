# Network AI Knowledge Base



### Purpose



This repository contains curated and structured technical knowledge for a local AI network assistant powered by Qwen (Qwen3.6-35B-A3B) and Open WebUI.



### Initial Scope



The first version covers:



* Cisco OSPF
* Cisco BGP
* Cisco NAT
* Cisco SSH
* Cisco IOS troubleshooting



### Content Types



Documents are organized into the following types:



* Concepts
* Configuration guides
* Troubleshooting guides
* Command references
* Validated EVE-NG labs



### Source Priority



1\. Official vendor documentation

2\. RFCs and technical standards

3\. Cisco Press and trusted technical references

4\. Manually validated EVE-NG lab notes



### Current Status



Repository structure created. Knowledge documents have not yet been added.
